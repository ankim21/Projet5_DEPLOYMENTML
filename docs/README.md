# Futurisys — ML Model API

Le but de ce projet est de déployer un modèle de machine learning en production.

Pour cela, nous allons : 
- créer une API avec FastAPI pour exposer le modèle
- écrire des tests unitaires avec Pytest pour garantir sa fiabilité
- et gérer la version du code avec Git pour une collaboration fluide
